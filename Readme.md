## 🎯 About

This repository documents my complete journey of learning Data Structures and Algorithms (DSA). I'm following **Striver's A2Z DSA Course/Sheet**, one of the most comprehensive DSA resources available, and practicing every concept hands-on.

### What's Inside?
- 🎥 Code implementations from video tutorials
- 📝 Solutions to problems from Striver's DSA sheet
- 💡 Personal notes and insights
- 🔄 Regular updates as I progress

## 📂 Repository Structure

```
DSA/
│
├── 📹 video/
│   └── Code practiced alongside Striver's A2Z DSA YouTube playlist
│       - Step-by-step implementations
│       - Concept explanations
│       - Live coding practice
│
└── 📋 [Other Folders]/
    └── Solutions organized by topics from Striver's Course Sheet
        - Arrays
        - Linked Lists
        - Trees
        - Graphs
        - Dynamic Programming
        - And more...
```

### 🎥 Video Folder
Contains all the code that I write while watching Striver's video tutorials. Each file corresponds to a specific video/topic, allowing me to code along and understand concepts in real-time.

### 📚 Course Sheet Folders
Organized topic-wise folders containing solutions to problems from [Striver's A2Z DSA Sheet](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2). These include:
- Problem statements
- Solution implementations
- Time and space complexity analysis
- Alternative approaches (when applicable)
